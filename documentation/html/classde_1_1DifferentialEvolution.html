Parameters

populationSizeNumber of agents in each optimization step
randomSeedSet random seed to a fix value to have repeatable (non stochastic) experiments
shouldCheckConstraintsShould constraints bee checked on for each new candidate. This check check may be turned off to increase performance if the cost function is defined and has no local minimum outside of the constraints.
callbackOptional callback to be called after each optimization iteration has finished. Optimization iteration is defined as processing of single population with SelectionAndCorssing method.
